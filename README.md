Experiment 1: Image Acquisition and Display
This experiment implements the fundamental operations involved in handling digital images using OpenCV. It covers the complete workflow of reading images from disk, storing them in memory, and displaying them on the screen using OpenCV display windows. The experiment also includes saving processed images back to disk in different formats. In addition, color space conversion operations such as converting RGB images to grayscale are performed to demonstrate how image data can be represented in different forms for analysis. This experiment helps in understanding how digital images are loaded, viewed, and manipulated programmatically, which forms the foundation for all further computer vision operations.

Experiment 2: Image Enhancement
This experiment focuses on improving the quality and visibility of images through enhancement techniques. Methods such as contrast stretching and histogram equalization are applied to increase the dynamic range and improve contrast in low-quality images. Brightness and contrast adjustments are also implemented to control image intensity levels and enhance overall appearance. These techniques are particularly useful when dealing with poorly illuminated, noisy, or faded images. Through this experiment, students gain practical exposure to visual quality improvement techniques widely used in photography, medical imaging, and surveillance applications.

Experiment 3: Image Transformation
This experiment demonstrates various geometric image transformation techniques used to modify an image’s size, orientation, and spatial location. Operations such as scaling (resizing), rotation, and translation are implemented to manipulate the position and alignment of images. Affine transformations are also introduced to show how images can be warped while preserving straight lines and parallelism. These transformations are essential in applications such as image registration, motion tracking, object alignment, augmented reality, and robotics. The experiment provides hands-on understanding of how pixel coordinates change during transformations.

Experiment 4: Edge Detection
This experiment implements classical edge detection algorithms such as Sobel, Prewitt, and Canny to identify and extract object boundaries from images. Edge detection helps detect regions where intensity values change sharply, which usually corresponds to object outlines or structural details. The experiment compares the performance of different edge detectors in terms of accuracy, smoothness, and noise sensitivity. Edge detection is a fundamental step in many computer vision tasks such as feature extraction, object recognition, medical image analysis, and navigation systems.

Experiment 5: Morphological Operations
This experiment applies basic morphological operations such as erosion, dilation, opening, and closing on binary and grayscale images. These operations use structuring elements to modify image structures and are useful for removing small noise, filling gaps, separating connected objects, and enhancing important object shapes. Morphological processing is commonly used in segmentation, character recognition, shape analysis, and industrial inspection systems. Through this experiment, students learn how structural transformations can improve object clarity and prepare images for further analysis.

Experiment 6: Convolution, Filtering, and Motion Blur
This experiment demonstrates convolution-based filtering techniques used for image smoothing, sharpening, and simulating motion effects. Filters such as mean (averaging) and Gaussian filters are applied to reduce noise and blur details, while sharpening filters enhance edges and fine details. Motion blur is simulated using directional convolution kernels that mimic camera movement. This experiment helps students understand the concept of kernel-based filtering and its impact on image quality. These techniques are widely used in photography, video processing, and pre-processing pipelines for machine learning.

Experiment 7: Corner Detection
This experiment focuses on detecting key interest points in images using algorithms such as Harris Corner Detection. Corners represent regions with strong variation in intensity in multiple directions and are useful for tasks like feature matching and tracking. The experiment also introduces feature extraction techniques such as SIFT, which detect and describe keypoints for object recognition and image alignment. Corner detection is a crucial foundation for advanced applications such as 3D reconstruction, augmented reality, and robot vision.

Experiment 8: Texture Segmentation using Gabor Filters
This experiment performs texture-based image segmentation using a bank of Gabor filters tuned to different orientations and spatial frequencies. Texture features extracted from these filtered images are used to classify and segment regions with similar texture patterns. Gabor filters are biologically inspired and mimic human visual perception, making them highly effective in fields such as biometrics, remote sensing, material inspection, and medical imaging. This experiment demonstrates how texture information can be used beyond simple color or intensity-based segmentation.

Experiment 9: Image Segmentation
This experiment implements a variety of image segmentation techniques used to partition an image into meaningful regions. Methods such as thresholding, region-growing, and clustering-based segmentation are applied to separate objects from the background. The experiment also compares traditional segmentation techniques with learning-based segmentation approaches to highlight differences in accuracy and robustness. Image segmentation is a key step in applications such as medical diagnosis, object detection, traffic monitoring, and scene understanding.

Experiment 10: Object Detection
This experiment focuses on detecting and localizing objects in images using both traditional computer vision techniques and deep learning-based models. Classical methods rely on feature extraction and pattern matching, while modern approaches use pre-trained deep neural networks such as YOLO or SSD to identify multiple objects with bounding boxes. Object detection is widely applied in surveillance systems, autonomous vehicles, security monitoring, smart retail, and assistive technologies. This experiment introduces students to real-world AI-driven vision applications.
